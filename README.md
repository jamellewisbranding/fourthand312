# Fourth & 312

Independent Chicago Bears fan page at https://fourthand312.com/.

- `site/` is the published website (plain HTML and CSS, no build step).
- `netlify.toml` tells Netlify to publish `site/`.
- `RUNDOWN.md` is the guide for the weekly 312 Rundown update.

To change the site, edit files in `site/`. Merging into `main` publishes it.
